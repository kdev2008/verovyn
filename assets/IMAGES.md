# Verovyn Image Library

All website photographs and logo files are bundled under `assets/images/` and can be replaced by files with the same names. Images are referenced by local relative paths (HTML or `assets/css/site.css`). No image depends on a remote service.

## Brand artwork
- `verovyn-original-logo.png`: Original user-supplied logo.
- `verovyn-logo-horizontal.webp`: Header/footer lockup made by rearranging crops of the original logo artwork.
- `assets/favicon.png`: Favicon crop of the original brand emblem.
